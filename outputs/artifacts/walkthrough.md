# Walkthrough

## 1. Rule Explained (`G4` - `rule_metadata_contradiction` in `discovery_agent/risk_rules.py`)
I implemented `rule_metadata_contradiction` in `discovery_agent/risk_rules.py` to detect mismatches between structured portal metadata and prose documentation or sample findings. Specifically, when `declared_metadata.has_missing_values` is `"no"` (or `missing_values_symbol` is null), the rule scans `documentation_excerpts` and `quality_notes` for evidence of missing values or sentinel codes (such as `-200`, `-999`, or `"missing values"`). On `link.uci_360` (`outputs/UC1/records/link.uci_360.json`), UCI's API declares `has_missing_values: "no"`, whereas `notes.summary` states `"Missing values are tagged with -200 value"`; the rule raises `DQ-METADATA-CONTRADICTION` (`major`) so downstream engineers do not treat `-200` readings as physical concentrations.

## 2. Claim in `signoff.json` Traced to Its Record Field
In `outputs/UC2/signoff.json`, the `traced_conclusion` cites `source_id: "api.nager_public_holidays"` and `record_field: "licence.evidence"`. In `outputs/UC2/records/api.nager_public_holidays.json`, `licence.evidence` documents that Nager.Date's GitHub repository carries an MIT licence for the software code (`github.com/nager/Nager.Date/blob/main/LICENSE`) with no licence covering the holiday dataset itself (`licence.name` is omitted/null). Consequently, `rule_licence` raises `LIC-UNKNOWN` (`blocker`) and `outputs/UC2/feasibility_memo.md` marks the source `not_feasible` for commercial production until Legal or Nager.Date provides written data terms (recorded in `could_change_if`).

## 3. Rejected Source and Why
I rejected `https://catalog.data.gov/dataset/open-air-chicago-hour-aggregations` (`link.data_open_air_chicago_hour_aggre_d4970b` in `outputs/UC1/discovery_results.json` and `outputs/artifacts/review_UC1.md`). First, the dataset covers Chicago (United States) rather than `UC1`'s primary geography (`IT`, northern Italy), triggering `COV-GEO-MISMATCH`. Second, `catalog.data.gov` is intentionally excluded from `config/allowlist.json` (`G6`), so when accepted at the candidate gate to test the guardrail, `HttpClient` refused the request with `DOMAIN_NOT_ALLOWLISTED` (`ACC-UNREACHABLE`), proving the domain allowlist blocks unapproved external hosts.

## 4. Memo Conclusion
In `outputs/UC1/feasibility_memo.md` (Section 1 & Section 3), the memo concludes that `link.uci_360` is `feasible_with_conditions` strictly for the `prototype` window (`2004-03-10` to `2005-04-04`) and cannot be used for the `production` window (`2024-01-01` to `2025-12-31`). This conclusion is driven by `G5` Calibration Rule 5 in `discovery_agent/prompts/risk_assessor.md`: although `rule_temporal_coverage` raises `FRS-STALE` because the data is 21.5 years old, Rule 5 preserves historical public benchmarks for offline method prototyping once `-200` sentinels are replaced with nulls, attribution is included, and Legal clears the research-only note.
